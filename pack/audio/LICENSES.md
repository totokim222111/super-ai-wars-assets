## 일반·중요 선택음 (2026-11-14)

- 일반 결정: Kenney Interface `select_001.ogg` (40.39ms). 커서: `click_004.ogg` (21.77ms). CC0, https://kenney.nl/assets/interface-sounds . 승인 S1 로컬 원본에서 MP3로 재인코딩, 시작/끝 짧은 페이드·음량 조절.
- 중요 선택 `important`: 기존 `confirmation_002.ogg` 소리·MP3를 보존. 스토리 분기·일회성 선택·출격 확정·NG+ 시작에서만 사용.
- 클릭 파일 RMS 0.06 이하/피크 0.3 이하, 엔진 UI gain 0.5를 적용해 최종 RMS 0.03 이하/피크 0.15 이하 (사용자 볼륨·호출 gain 적용 전). 전투 효과음에는 UI 감쇠를 적용하지 않음.
